# 🥂 Юбилей · 20 октября

Сайт для координации подготовки к юбилею на 200 гостей. Каждый родственник открывает ссылку, выбирает одну из задач по подготовке, вписывает своё имя и отмечает прогресс. Прогресс виден всем в реальном времени.

**Сайт:** https://claude.ai/artifact/THuECebP8jYA5iPMRkWH4K

## Что есть на сайте

- Дата и краткая информация о мероприятии (20 октября, 200 гостей, банкет)
- Общая шкала готовности — сколько задач разобрано и сколько уже выполнено
- Список из 10 задач с описанием, статусом и именем ответственного
- Возможность взять задачу на себя, оставить заметку о ходе работы и отметить её выполненной

## Как пользоваться

1. Откройте ссылку на сайт и найдите свободную задачу.
2. Нажмите на неё, впишите своё имя и нажмите «Взять на себя».
3. По ходу подготовки оставляйте заметку о прогрессе и отмечайте задачу готовой, когда всё сделано.

## Важно при передаче ссылки

Чтобы родственники могли реально брать задачи и сохранять изменения, ссылку нужно отправлять с доступом **на редактирование или комментирование**, а не только «только просмотр» — иначе кнопки будут работать лишь у владельца страницы.

## Ограничения

- Автоматических email-уведомлений об изменениях нет — статус обновляется на странице в реальном времени, её нужно открывать самостоятельно, чтобы видеть прогресс.
- Данные о задачах хранятся в общем хранилище страницы и видны всем, у кого есть ссылка с соответствующим доступом.
